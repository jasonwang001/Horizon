### [基因组语言模型首次生成可行噬菌体基因组](https://www.reddit.com/r/MachineLearning/comments/1vjj4pr/r_generative_design_of_novel_bacteriophages_with/) ⭐️ 9.0/10

研究人员利用前沿基因组语言模型 Evo 1 和 Evo 2，以裂解性噬菌体 ΦX174 为设计模板，首次实现了完整噬菌体基因组的生成式设计。实验测试表明，AI 生成的基因组中产生了 16 个具有显著进化新颖性的可行噬菌体。这一成果验证了基因组语言模型在整体基因组尺度上生成功能序列的能力，为合成生物学和 AI 驱动的生物设计带来了重大进展。

reddit · r/MachineLearning · /u/moschles · 8月9日 07:11

**「背景」** 基因组语言模型是专门在原始 DNA 序列上训练的 AI 模型，能够以单核苷酸分辨率处理和生成基因组序列。Evo 1 于 2024 年 2 月发布，Evo 2 则于 2026 年 2 月发布，后者拥有 400 亿参数、100 万碱基的上下文长度，并在超过 9 万亿个核苷酸上训练，覆盖多种真核和原核基因组。噬菌体是感染细菌的病毒，本文使用的设计模板ΦX174 是一种典型的裂解性噬菌体，其基因组较小且结构清晰，适合作为生成设计的验证对象。

**「影响」** 对于合成生物学和噬菌体疗法领域的研究者与开发者，这项研究首次证明基因组语言模型能够生成具有完整基因组规模、可存活的噬菌体（实验验证得到 16 株新型噬菌体），且生成的噬菌体混合物可快速克服三种大肠杆菌菌株对ΦX174 的耐药性，指向基于 AI 设计噬菌体疗法的可行路径。

### [GitHub Models 退役，CI 开发者需迁移](https://simonwillison.net/2026/Aug/9/github-models-is-now-retired/#atom-everything) ⭐️ 7.0/10

GitHub 于 2026 年 7 月 30 日宣布 GitHub Models 正式退役，该服务曾为 GitHub Actions 中的代码提供统一 LLM API 和模型 playground，并允许直接使用环境内的 GitHub API 密钥执行提示词。Simon Willison 直到自己的 simonw/research 仓库 GitHub Actions 运行失败才注意到此事，失败信息称服务处于“计划退役停电”（scheduled retirement brownout），但消息已经过时，退役实际已完成。GitHub 未说明关停原因，Willison 推测与编码代理模式使免费或补贴 token 成本过高有关。他已在工作流中改用带月度支出上限的 OpenAI API 密钥，并使用 GPT-5.6 Luna 生成 README 文件夹摘要。

rss · Simon Willison · 8月9日 22:48

**「背景」** GitHub Models 是 GitHub 提供的一个统一模型平台，包含模型游乐场、模型目录、推理 API 和自带密钥（BYOK）功能，并允许开发者在 GitHub Actions 中直接使用环境内已有的 GitHub API 密钥调用大语言模型。微软于 2026 年 6 月宣布停止向新客户开放该服务，随后在 2026 年 7 月 30 日正式将其完全退役，届时上述功能对任何客户都不再可用。

**「影响」** 此次停用直接影响了依赖 GitHub Actions 环境中自带 GitHub API 密钥调用统一 LLM 接口的开发者，他们的 CI 工作流可能因模型不可用而失败，必须迁移到 OpenAI、OpenRouter 等替代供应商，并自行配置 API 密钥、月度限额与调用逻辑。开发者应像对待任何托管 AI 平台一样，提前盘点依赖、替换供应商特定假设并建立退出计划，以降低类似平台停用带来的中断风险。
